# Java_Shooting-game

2020년 Java 기말 프로젝트로 만든 Swing/AWT 슈팅 게임입니다.

## 실행

Eclipse에서 [final](final) 폴더를 Java 프로젝트로 가져온 뒤 [Main.java](final/src/Main.java)를 실행합니다. 이미지가 `src/img` 상대 경로로 로드되므로 실행 작업 디렉터리는 `final`로 설정합니다.

## 코드

- [Main.java](final/src/Main.java): 실행 진입점
- [shootingGame.java](final/src/shootingGame.java): 화면과 키 입력
- [Game.java](final/src/Game.java): 게임 진행
- [Enemy.java](final/src/Enemy.java), [EnemyAttack.java](final/src/EnemyAttack.java), [PlayerAttack.java](final/src/PlayerAttack.java): 적과 공격
- [img](final/src/img): 화면 이미지
